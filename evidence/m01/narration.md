1. Executing npx expo starts the local development server and activates the Metro, the JavaScript bundler that prepares the app code to run on the device, emulator or simulator.
2. The native shell executes the code, lays out the views, and draws the final pixels on your screen.
3. When you run npx expo run:ios or npx expo run:android, Expo moves away from using the generic Expo Go app and builds a custom native development build specifically for your project.
